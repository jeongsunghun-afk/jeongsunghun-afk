# 정성훈 · Jeong Sunghun

**보행 로봇 제어 소프트웨어 엔지니어**  
시뮬레이션에서 설계한 제어기를 실제 로봇에서 걷게 만드는 일을 합니다.

---

## 하는 일

**보행 제어기 설계**  
모델 예측 제어(MPC)와 전신 제어(Whole-Body Control, QP 기반)를 결합한 이족·사족 보행 제어기를 설계하고 C++로 구현합니다. 걷기·트롯·달리기 같은 보행 패턴, 발 디딤 계획, 관절 목표 추종 구조를 다룹니다.

**실기 배포와 sim-to-real**  
임베디드 리눅스에서 도는 실시간 제어 루프를 만들고, EtherCAT·CAN으로 연결된 액추에이터를 구동합니다. 지연·센서 잡음·전달부 유격처럼 실기에서만 드러나는 요소를 시뮬레이션에 넣어 실기 전에 검증하고, 하드웨어 추상화 계층으로 시뮬레이션과 배포 코드 경로가 같은 결과를 내는지 확인합니다.

**상태 추정과 실기 문제 진단**  
IMU와 다리 기구학을 융합하는 접촉 기반 상태 추정기를 다룹니다. 실기 로그를 분석해 센서 지연, 진동, 통신 장애 같은 문제의 원인을 찾고, 시뮬레이션에서 재현한 뒤 고칩니다.

**액추에이터 시스템 식별**  
처프 신호와 정적 시험으로 로터 관성·마찰·지연·강성을 식별해 시뮬레이션 모델과 제어기 게인에 반영합니다.

**강화학습과 최적화 기반 제어 연구**  
Isaac Lab에서 지형 커리큘럼 기반 보행 정책을 학습시키고, 비선형 MPC·발판 계획·contact-implicit MPC 등 여러 제어 방식을 같은 조건에서 비교합니다.

## 일하는 방식

- **가설 → 시뮬레이션 재현 → 실기 검증** 순서로 원인을 좁힙니다. 재현되지 않는 수정은 넣지 않습니다.
- 바꾼 것과 바꾸지 않은 것을 숫자로 남깁니다. 회귀 검증을 통과하지 못한 변경은 기본값으로 두지 않습니다.
- 잘 안 된 결과도 기록합니다. 무엇이 안 되는지 아는 것이 다음 결정을 빠르게 합니다.
